# Vadgaard Corne Keymap

A Corne adaptation of the Vadgaard Planck layout for the 46-key `LAYOUT_split_3x6_3_ex2` shape.

- `Esc/Ctrl` sends Escape when tapped and Left Control when held.
- `F/Vim` sends `F` when tapped and holds the Vim layer when held.
- Left-side modifiers use left-handed variants; right-side modifiers use right-handed variants.
- `Adjust` is available by holding `Lower` and `Raise` together.
- Blank keys are intentionally disabled unless they are the active layer key.

```text
|Shift |   Z  |   X  |   C  |   V  |   B  |------'  `------|   N  |   M  |   ,  |   .  |   /  |Shift |
```


## Adjust

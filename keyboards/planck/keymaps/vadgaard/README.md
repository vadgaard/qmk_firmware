# Vadgaard Planck Keymap

A compact QWERTY Planck layout with momentary symbol/number layers, a keypad-style Fn layer, and a small Vim navigation layer.

- `Esc/Ctrl` sends Escape when tapped and Left Control when held.
- `F/Vim` sends `F` when tapped and holds the Vim layer when held.
- Left-side modifiers use left-handed variants; right-side modifiers use right-handed variants.
- `Adjust` is available by holding `Lower` and `Raise` together.
- Blank keys are intentionally disabled unless they are the active layer key.

## Adjust

`Adjust` keeps the useful Planck default maintenance controls, with the removed Qwerty/Colemak/Dvorak/Plover layer-switching keys left disabled.

```text
                     v------------------------RGB CONTROL--------------------v
,-----------------------------------------------------------------------------------.
|      | Boot |Debug | RGB  |RGBMOD| HUE+ | HUE- | SAT+ | SAT- |BRGTH+|BRGTH-| Del  |
|------+------+------+------+------+------+------+------+------+------+------+------|
|      |      |MUSmod|Aud on|Audoff|AGnorm|AGswap|      |      |      |      |      |
```
